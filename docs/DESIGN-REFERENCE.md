orange text accents, five thematic sections and journey graphic. Keep diagram colors
semantic. Limit adaptations to readable responsive layouts, consistent spacing,
accessible navigation and text contrast. Exact color tokens, licensed font identity,
image cropping, mobile navigation and any section restructuring require approval.

human font name. Do not claim the exact family is known. Hero title rendered white;
other palette values remain to be extracted/confirmed, not guessed as exact originals.

Canva biography includes historical school/experience claims. They are source copy,
not newly verified current facts; reconfirm before publishing updated biography.
