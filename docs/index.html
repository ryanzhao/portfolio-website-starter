快速开始

需要 Node.js 24.14.x 和 npm。克隆仓库后，在仓库根目录执行：

npm ci
npm run dev

打开 http://127.0.0.1:3000。完整安装、Cloudflare 与 Sanity 配置说明见中文源码指南。
